# Kitagawa Codex Addons

KCA is a client-side Fabric mod for Hypixel SkyBlock. Download the JAR that matches your Minecraft version.

| Minecraft | KCA 1.13.8 |
| --- | --- |
| 26.1.2 | [Download for Minecraft 26.1.2](https://raw.githubusercontent.com/VK-Airk/Kitagwa-CA/v1.13.8/KCA-1.13.8-mc26.1.2.jar) |
| 26.2 | [Download for Minecraft 26.2](https://raw.githubusercontent.com/VK-Airk/Kitagwa-CA/v1.13.8/KCA-1.13.8-mc26.2.jar) |

Close Minecraft, replace your previous KCA JAR in your Fabric profile’s mods folder, and restart. Use Fabric API for the same Minecraft version.

In 1.13.8, the Nucleus reward reveal uses bundled artwork for rare drops and Minecraft’s own loot bundle texture. The original spin is available under **CN Gambling → Legacy 3D reward**.
